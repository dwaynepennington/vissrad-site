Integrated project delivery — demonstration build

One dataset, eleven tools

VissRad connects estimating, cost, schedule, work packaging, completions and finance across the capital project lifecycle — with a document-exchange layer between the modules and a shared analytics model beneath them. Every module below runs against the same seeded demonstration project, so a change in one shows up where it matters in the others.

About this demo. Each module is a browser build of the corresponding VissRad tool — most from the desktop applications, Estimating from the Master EPC estimate workbook, and Analytics & Exports from the published Power BI report families, whose original packages are downloadable inside that module. Data is synthetic and held in your browser only — nothing you enter leaves this page, and Reset demo inside any module restores the seeded dataset.
