VRSmartPlan

From the estimate to a working schedule and its controls.

VRSmartPlan, formerly VRProject, brings thirteen tools together on one tool bar: VREstimator, the VRScheduler Schedule Editor and schedule analysis, VRPlanner and seven specialist planners, VRTAR turnarounds, VRCMMS maintenance and VRControls project controls and cost tracking. The Schedule Editor sends its schedule to VRControls to set the baseline, then each statused update to report earned, actual and budget hours, SPI and CPI. It runs the same online in the browser or installed on a Windows or Mac computer.

Download

VRSmartPlan on your own computer.

All thirteen tools installed on a Windows or Mac computer. It runs from the installed files: no internet connection, no server and no administrator rights.

Windows 10 and 11

Install on Windows

Double-click the zip to open it, then double-click Install VRSmartPlan; there is no need to extract it first. It adds a Desktop icon and a Start menu entry for each tool, and opens in Microsoft Edge in its own window.

macOS

Install on a Mac

Double-click the zip, then double-click Install VRSmartPlan (Mac). The apps go in ~/Applications/VRSmartPlan and open in Google Chrome or Microsoft Edge. macOS asks once to allow the installer.

Coming from VRProject

Your records come with you

On a computer that has VRProject installed, the first VRSmartPlan install copies its records across and leaves VRProject as it was. Records stay on the computer in a private profile and are not uploaded anywhere.
